# Differential Neural Gabor Rasterization

This is the rasterization engine for the paper "Neural Gabor Splatting: Enhanced Gaussian Splatting with Neural Gabor for High-frequency Surface Reconstruction". If you can make use of it in your own research, please be so kind to cite us.

This repository is derived from the official 2D Gaussian Splatting codebase.

Base repository:
- 2D Gaussian Splatting Rasterizer: https://github.com/hbb1/diff-surfel-rasterization.git

Base commit:
- e0ed0207b3e0669960cfad70852200a4a5847f61

This repository was created by copying and restructing the code from the above commit and then extending it for Neural Gabor Splatting.
